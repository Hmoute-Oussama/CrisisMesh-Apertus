About CrisisMesh Apertus

Offline-first, evidence-aware crisis information system. All processing is local; no cloud API keys.

  • Every factual claim has an EvidenceLink back to the report it came from.
  • Uncertainty is never converted to false certainty. Abstention is a valid answer.
  • Contradictions are surfaced, not resolved by the system.
  • Injection attempts are detected and contained.
